# Barberly — interface demonstrativa

Este repositório mostra uma **amostra da interface** do [Barberly](https://barberly.barberlyapp.workers.dev/), sistema de gestão para barbearias. Foi preparado para apresentação de portfólio com React e TypeScript.

Inclui telas de visão geral, agenda, serviços e profissionais. Os dados são fictícios; agendamentos adicionados ficam apenas na memória da página.

O código da aplicação publicada não está inteiro aqui. Esta amostra não inclui autenticação, cobrança, infraestrutura, banco de dados nem chamadas de API.

## Executar localmente

```bash
npm install
npm run dev
```

Para verificar a compilação, use `npm run build`.
